# 바이브 코딩 웹 발표자료 제작

**프로젝트:** 「혼자서 앱 하나 굴리기」 인터랙티브 웹 발표자료 제작  
**사용 도구:** Claude Code, HTML, CSS, JavaScript  
**역할:** 콘텐츠 기획, 프롬프트 작성, 디자인 방향 설정, 결과물 검수  
**결과물:** 14장 구성의 인터랙티브 웹 발표자료

---

## 한 줄 요약

Claude Code를 활용해 아이디어와 요구사항을 자연어로 전달하고,
HTML·CSS·JavaScript 기반의 인터랙티브 웹 발표자료를 제작했습니다.

---

## 왜 이렇게 작업했나

일반적인 PPT가 아닌 사용자가 직접 눌러보고 값을 바꿔볼 수 있는
인터랙티브한 발표자료를 만들어보고 싶었습니다.

직접 모든 코드를 작성하기보다 원하는 화면과 기능을 구체적으로 설명하고,
Claude가 구현한 결과물을 확인하며 반복해서 개선하는
바이브 코딩 방식으로 진행했습니다.

---

## 제작 과정

### 1. 콘텐츠 구성

'혼자서 앱 하나를 운영한다면 어떤 일을 하게 될까?'를 주제로
전체 발표 흐름을 구성했습니다.

제품 소개부터 기획·개발·디자인·CS·마케팅,
광고비와 자동화, AI 활용까지 14개의 화면으로 구성했습니다.

### 2. 웹 디자인 구현

일반적인 슬라이드보다 하나의 웹사이트처럼 보이도록 방향을 잡고,
HTML·CSS를 활용해 화면과 레이아웃을 구현했습니다.

### 3. 인터랙션 구현

Claude Code를 활용해 다양한 기능을 추가했습니다.

- 슬라이드 이동 및 전체 보기
- 역할별 플립 카드
- 업무 타임라인
- 업무시간 배분 시뮬레이터
- ROAS 계산기
- 고객 요청 → 보정값 변환 데모
- 탭·아코디언 UI

### 4. 반복 수정

실제 화면을 확인하면서 디자인이나 동작에서 아쉬운 부분을
자연어로 요청하고 반복적으로 수정했습니다.

이를 통해 원하는 결과를 구체적으로 설명하고,
AI와 함께 결과물을 발전시키는 바이브 코딩 방식을 경험했습니다.
