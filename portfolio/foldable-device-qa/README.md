# 📲 픽미 폴더블 기기 UI QA

> 2026.10 · Samsung Remote Test Lab

## Background

2026년 10월, Google Play에 폴드폰 사용자의 **1점 리뷰**가 등록됐습니다.
리뷰를 계기로 삼성 Remote Test Lab에서 실제 폴더블 기기를 원격으로 사용해 픽미 앱의 폴더블 호환성을 점검했습니다.

## My Role

테스트 환경 구성 · 시나리오 설계 · 화면별 문제 확인 · 우선순위 판단 · QA 보고서 작성 · 개선 요청 정리

---

## Approach

### 1. 테스트 환경

| 항목 | 내용 |
|---|---|
| 테스트 서비스 | Samsung Remote Test Lab |
| 테스트 기기 | Galaxy Z Fold 시리즈 |
| 테스트 상태 | 접은 화면 · 펼친 화면 · 가로 모드 |
| 테스트 범위 | 홈 → 촬영 · 업로드 → 사진 편집 → 장바구니 → 결제 |

### 2. 화면별 문제 정리

접은 화면에서는 정상이었지만, **펼친 화면에서 핵심 화면의 UI가 깨지는 문제**를 확인했습니다.
문제마다 사용자 영향도를 기준으로 우선순위를 매겼습니다.

| 화면 | 문제 | 우선순위 |
|---|---|---|
| 사진 편집 | 사진이 잘리고 편집 아이콘이 표시되지 않음 | 🔴 긴급 |
| 사진 편집 | 규격 변경 시 가이드라인 · 사진 배치 비정상 | 🟠 높음 |
| 장바구니 | 사진이 확대 · 잘리고 주문 정보와 겹침 | 🟠 높음 |
| 공통 | 펼친 화면에 맞는 반응형 레이아웃 미흡 | 🟠 높음 |
| 홈 | 화면 크기에 비해 폰트 · 콘텐츠가 지나치게 큼 | 🟡 보통 |

👉 사진 편집 도구가 보이지 않으면 주문 자체가 불가능하므로 **최우선 수정 대상**으로 분류했습니다.

### 3. 개선 요청 작성

개발팀이 바로 작업할 수 있도록 화면별 기대 동작을 구체적으로 정리했습니다.

- **사진 편집** : 원본 비율 유지, 편집 도구 항상 노출, 35×45mm · 50×50mm 등 규격 변경 시 레이아웃 유지, 저장 버튼과 시스템 내비게이션 겹침 해소
- **장바구니** : 미리보기 비율 및 최대 크기 제한, 이미지 · 옵션 · 버튼 겹침 해소
- **홈 · 공통** : 화면 너비에 따른 폰트 · 배치 조정, 펼침 · 접힘 전환 시 레이아웃 유지, **일반 스마트폰 UI는 그대로 유지**

### 4. 재검증 기준

수정 후 접은 화면 · 펼친 화면 · 가로 모드 각각에서 홈부터 결제까지 전체 주문 과정을 다시 확인하도록 재검증 범위를 정했습니다.

---

## Result

- 폴더블 기기 UI 문제 5건 발견 및 우선순위 분류
- 화면별 개선 요청을 담은 QA 보고서 작성
- 수정 후 재검증 시나리오 정의

## What I Learned

- 사용자 리뷰 하나가 특정 기기 환경의 숨은 문제를 알려주는 신호가 될 수 있다는 점
- 기기가 없어도 원격 테스트랩으로 실제 환경을 검증할 수 있다는 점
- 문제를 나열하는 것보다 **사용자 영향도에 따른 우선순위**를 함께 전달해야 개발 일정에 반영된다는 점
- 수정 요청에는 "바뀌지 말아야 할 것"(일반 기기 UI)도 함께 적어야 한다는 점
