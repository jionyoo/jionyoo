05 — 도구

혼자 감당하려면, 스택이 좁아야 한다

CLIENT

Flutter · Dart

iOS와 안드로이드를 한 코드베이스로. 화면 하나 고치면 두 스토어에 동시에 반영됩니다. 1인 체제에서 가장 크게 남는 장사.

OPS

초안은 맡기고, 판단은 내가
