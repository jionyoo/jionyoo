# 📌 2026.10 Monthly Growth Log

10월에는 일본 증명사진 웹서비스 **마루포토(Maroofoto)** 개발을 중심으로 기획부터 실제 구현까지 업무 범위를 확장했습니다.

Claude를 활용한 웹 개발과 디자인 자동화, QA, 마케팅 업무를 경험하며 AI를 실제 서비스 제작과 운영에 활용하는 역량을 키웠습니다.

# 1. Web Development & Product Planning

## 마루포토 웹서비스 개발

9월에 설계한 일본 콘비니 증명사진 웹사이트를 실제 작동하는 서비스로 구현했습니다.

### Worked On

- React · TypeScript · Tailwind 기반 웹 개발
- 사진 업로드 → 규격 조정 → 결제 → 결과 수령까지 17개 화면 구현
- 일본어·한국어 다국어 구조 설계 (번역 키 641개)
- Firebase 연동 및 사진 보관·삭제 정책 적용
- 회원가입 없는 주문 및 재수령 방식 설계
- 배경 제거 API의 서버 연동 및 오류 처리

### Learned

- 기획한 화면을 실제 웹서비스로 구현하는 과정 이해
- 프론트엔드와 서버·데이터 구조에 대한 이해 확대
- 외부 API 오류를 발견하고 해결하는 경험
- 미완성 기능과 구현 완료 기능을 구분해 관리하는 방법

👉 **기획과 디자인에서 실제 서비스 개발까지 역량 확장**

# 3. App Store Review & AI Design Workflow

## App Store 심사 통과 🎉

7월부터 이어온 App Store 심사 대응 끝에 **10월 App Store 심사를 통과**했습니다.

iOS 앱 심사 재등록을 위해 스토어 스크린샷을 수정하고, Claude × Figma 워크플로우로 기존 수작업 방식을 개선했습니다.

### Result

- 반려 사유를 반영한 스크린샷 · 문구 · 메타데이터 수정
- **App Store 심사 통과**

### Learned

- Claude와 Figma를 연결한 디자인 작업
- 반복적인 이미지 수정 작업 간소화
- AI를 활용한 디자인 작업 효율 향상

👉 **반복된 반려를 끝까지 대응해 심사 통과, AI로 디자인 수정 작업 생산성 향상**

👉 **실제 사용 환경을 고려한 앱 품질 관리 역량 강화**

# 7. Summary

## Before

서비스 기획 및 Figma 기반 화면 디자인 중심

## After

AI를 활용해 웹서비스를 직접 구현하고, 기술적인 문제 해결과 서비스 운영까지 연결하는 단계로 성장
