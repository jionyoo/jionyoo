# 증명사진 셀프 촬영 가이드

## Background

사용자가 증명사진 규정을 정확히 이해하지 못해 반복적인 반려와 문의가 발생하고 있었습니다.

특히 얼굴 각도, 배경, 표정, 안경, 머리카락 등 동일한 유형의 실수가 지속적으로 발생하고 있었으며, 텍스트 위주의 안내만으로는 기준을 직관적으로 전달하기 어려운 상황이었습니다.

---

## My Role

* 반려 사례 분석
* 촬영 가이드 구조 설계
* AI 이미지 생성 프롬프트 작성
* UX 문구 작성 및 개선
* 최종 가이드 콘텐츠 제작

---

## Approach

### 1. 반려 유형 구조화

실제 운영 과정에서 반복적으로 발생하는 반려 사례를 분석하여 아래와 같이 카테고리화했습니다.

* 얼굴 각도
* 자세 및 시선
* 얼굴 크기
* 배경
* 안경
* 머리카락
* 액세서리
* 표정
* AI 이미지 및 과도한 보정

---

### 2. AI 이미지 생성

사용자가 통과 사례와 반려 사례를 쉽게 구분할 수 있도록 AI 이미지 생성 프롬프트를 설계했습니다.

특히 다음 사항을 고려하여 반복적으로 프롬프트를 개선했습니다.

* 실제 증명사진과 유사한 결과물 생성
* 문제 요소가 명확하게 보이는 구성
* 통과/반려 기준이 직관적으로 전달되는 이미지 제작
* 전체 가이드의 톤앤매너 통일

---

### 3. UX 개선

텍스트 설명 중심이 아닌 시각적 비교 중심으로 구성하여 사용자가 빠르게 이해할 수 있도록 설계했습니다.

* 좋은 예 / 나쁜 예 비교
* 핵심 문구 최소화
* 촬영 전 체크리스트 형태 구성

---

## Result

* 증명사진 셀프 촬영 가이드 제작
* AI 기반 예시 이미지 제작
* 반려 사례 시각화
* 운영 가이드 자산 확보

## What I Learned

* AI 이미지 생성에서 가장 중요한 요소는 프롬프트 설계라는 점
* 사용자는 긴 설명보다 시각적 예시를 더 빠르게 이해한다는 점
* 반복되는 운영 문제를 UX 콘텐츠로 해결할 수 있다는 점
* AI를 단순 생성 도구가 아닌 실제 서비스 개선 도구로 활용하는 경험을 얻을 수 있었습니다.
