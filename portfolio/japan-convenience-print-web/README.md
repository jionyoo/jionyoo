# 일본 콘비니 증명사진 웹 서비스

> 진행 중 · 2026.09 ~

## Background

일본에는 편의점 복합기로 증명사진을 인쇄하는 수요가 있으며, ピクチャン 등 선행 서비스가 시장을 점유하고 있었습니다.

기존 앱 서비스와는 가격 체계와 제공 범위가 달라 별도 브랜드의 웹 서비스가 필요했고, 짧은 기간 안에 배포 가능한 수준의 MVP를 설계해야 하는 상황이었습니다.

또한 인쇄 번호 발급이 자동화되지 않아 담당자가 수동으로 처리해야 하는 운영 제약이 있었습니다.

## My Role

- 경쟁 서비스 분석
- 정보 구조 및 화면 설계
- 상품 구조 재설계
- 한국어 · 일본어 UX 라이팅
- 프로토타입 제작
- 법적 표기 요건 정리
- 외부 서비스 약관 리스크 검토

## Approach

### 1. 경쟁 서비스 분석

일본 선행 서비스의 랜딩 구조를 분석하여 다음 패턴을 도출하고 적용했습니다.

- 가격을 헤드라인 상단에 배치
- 대응 편의점 브랜드 나열로 신뢰 확보
- 컬러 앵커 내비게이션
- 번호 매긴 추천 포인트 구성
- 충분한 설명량 (일본 사용자는 상세 정보를 선호)

### 2. 상품 구조 단순화

초기 5종(콘비니 번호 / 파일 / 번호+파일 / 파일+보정 / 전체)으로 설계했으나, 조합형 상품이 비교를 어렵게 만드는 문제가 있었습니다.

보정 기능을 별도 축으로 분리하고 **배달 방식 3종**으로 정리했습니다.

| 상품 | 가격 |
|---|---|
| 콘비니 번호만 | ¥200 |
| 제출용 파일만 | ¥400 |
| 콘비니 + 파일 | ¥500 |

### 3. 운영 제약의 UX 전환

인쇄 번호가 수동 발급이라 결제 후 약 30분의 대기가 발생합니다.

이를 숨기지 않고 **기대치 관리 화면**으로 설계했습니다.

- `인쇄 번호는 아직 발급되지 않았습니다`를 화면 최상단에 명시
- 접수 시각 · 예상 발송 시각 · 영업시간 병기
- 영업시간 외 접수 시 처리 시점 안내
- 메일 주소 입력을 필수화 (번호 전달 경로)

### 4. 상품별 결과 화면 분기

단일 결과 화면은 구매하지 않은 항목까지 노출되는 문제가 있었습니다.

- 번호만 구매 → 예약번호 + 인쇄 안내
- 번호+파일 구매 → 예약번호 + 파일 + 인쇄 안내
- 파일만 구매 → 파일 다운로드 (대기 화면 생략)

파일은 자동 생성되므로 파일만 구매한 경우 대기 단계를 거치지 않도록 플로우를 분리했습니다.

### 5. 이중언어 설계

전 화면을 한국어 · 일본어로 구성했습니다.

- 모든 요소에 Auto Layout 적용 → 번역 시 레이아웃 무손실
- 일본어판은 Noto Sans JP 적용 (한자 자형 차이 반영)
- 현지 용어 반영 : 복합기 → `マルチコピー機`, 인쇄 번호 → `プリント予約番号`
- 편의점 계열별 메뉴명 차이 명시 (세븐일레븐 `ネットプリント` / 그 외 `ネットワークプリント`)

### 6. 법적 요건 반영

일본 特定商取引法에 따른 표기 항목 13종을 정리해 전용 페이지로 설계했습니다.

반품 조건을 명시하지 않으면 법정 반품권이 자동 적용되므로, 주문 제작 디지털 상품 특성을 반영한 조항을 초안으로 작성했습니다.

### 7. 리스크 사전 검토

인쇄 번호 발급에 사용하던 외부 서비스의 이용약관을 검토한 결과, **개인 계정의 상용 이용이 금지 조항에 해당**함을 확인했습니다.

- 콘텐츠 판매 목적 이용 금지
- 서비스 재판매 금지
- 위반 시 사전 통지 없는 계정 삭제

법인 계약 경로와 문의 창구를 정리해 전달했습니다.

- 상품별 주문 플로우 분기 설계
- 프로토타입 연결 완료
- 特定商取引法 표기 초안 확보
- 서비스 운영 리스크 사전 발견 및 대응 방향 제시
