# 🎞 인터랙티브 웹 PPT 제작

**프로젝트:** Claude를 활용한 웹 발표자료 제작  
**사용 도구:** Claude, HTML, CSS, JavaScript  
**결과물:** 14장 인터랙티브 웹 프레젠테이션

---

## 📌 프로젝트 소개

Claude를 활용해 일반적인 PPT가 아닌
**직접 클릭하고 조작할 수 있는 웹 발표자료**를 제작했습니다.

주제 선정부터 디자인 방향, 기능 구현, 수정까지
Claude와 함께 작업했습니다.

---

## 💡 제작 과정

### 1. 주제와 구성 정하기

발표 주제 후보를 먼저 정리하고,
인터랙션을 다양하게 활용할 수 있는 주제를 선택했습니다.

발표 흐름과 14장의 슬라이드 내용을 구성한 뒤 제작을 시작했습니다.

### 2. 디자인 컨셉 만들기

사진과 관련된 주제에 맞춰
**사진 인화지 컨셉**으로 디자인했습니다.

- 재단 마크
- 사진 규격 라벨
- 필름 스트립
- 셔터 플래시 효과
- 4가지 메인 컬러 사용

주제와 디자인이 자연스럽게 연결되도록 구성했습니다.

### 3. 인터랙션 추가하기

단순히 보는 발표자료가 아니라
직접 눌러보고 값을 바꿀 수 있는 기능을 추가했습니다.

- 3D 플립 카드
- 24시간 타임라인
- 시간 배분 시뮬레이터
- 실시간 계산기
- Before / After 전환
- 탭 / 아코디언
- 키보드 및 모바일 슬라이드 이동

### 4. 수정 및 완성

완성된 결과물을 직접 실행해보며
디자인과 기능을 확인하고 필요한 부분을 수정했습니다.

전체를 다시 만드는 대신,
수정이 필요한 부분만 찾아 변경하는 방식도 경험했습니다.
