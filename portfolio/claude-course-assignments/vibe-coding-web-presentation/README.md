# 🎞 인터랙티브 웹 프레젠테이션

**사용 도구:** Claude, HTML, CSS, JavaScript  
**결과물:** 14장 인터랙티브 웹 프레젠테이션

> 가상의 1인 앱 `필름로그` 운영 사례를 설명하기 위해 만든 교육용 발표 자료입니다. 실제 서비스 운영 경력을 나타내는 프로젝트가 아닙니다.

## Background

슬라이드를 넘겨 보는 방식보다 발표 중 직접 조작할 수 있는 웹 형식이 1인 운영의 시간 제약과 의사결정을 설명하기에 적합하다고 판단했습니다.

## Approach

- 사진 서비스라는 주제에 맞춰 인화지, 재단선, 필름 스트립을 시각 요소로 사용했습니다.
- 역할 카드, 24시간 타임라인, 시간 배분 시뮬레이터, ROAS 계산기 등 내용을 직접 조작할 수 있게 구성했습니다.
- 14장의 흐름을 제품 소개, 운영 제약, 주요 사건, 자동화, 배운 점 순서로 설계했습니다.
- HTML, CSS, JavaScript를 한 파일에 담아 별도 설치 없이 실행되도록 만들었습니다.
- 키보드, 버튼, 모바일 스와이프 이동과 전체 보기 기능을 직접 실행하며 확인했습니다.

- [소스 코드 보기](./index.html)
- 슬라이드별 클릭 요소와 계산 결과가 즉시 반영되는 14장 웹 발표 자료 완성

## Learned

- 화면을 먼저 만들기보다 발표 흐름과 사용자의 조작 지점을 먼저 정해야 수정 범위가 줄어든다는 점
- AI가 만든 코드를 그대로 쓰기보다 기능별로 실행하고 오류가 난 부분만 좁혀 수정하는 방법
- 가상 사례를 공개할 때 실제 경험과 혼동되지 않도록 범위를 명확히 표시해야 한다는 점
