# 🛡 AI 보안과 윤리 발표 자료

**주제:** 딥페이크, 저작권, 규제 사이의 거버넌스 공백

**사용 도구:** Claude Cowork, PowerPoint

**결과물:** 5분 발표용 PowerPoint 6장

## Background

AI 보안과 윤리라는 넓은 주제를 짧은 발표 안에서 이해할 수 있도록, 딥페이크 위협과 저작권 쟁점, 규제 대응을 하나의 이야기로 연결하는 과제였습니다.

## Approach

- 업계 데이터 리포트, 법률 분석, 규제 해설처럼 성격이 다른 자료를 나눠 조사했습니다.
- 위협, 쟁점, 대응, 시사점 순서로 6장 발표 흐름을 구성했습니다.
- 핵심 수치와 사건을 표, KPI, 타임라인으로 바꿔 슬라이드당 메시지를 줄였습니다.
- 완성본을 콘텐츠 기획자, 시각 디자이너, 발표자 관점으로 나눠 동시에 검토했습니다.
- 공통으로 나온 피드백을 우선 반영하고, 표 렌더링 오류를 다시 확인해 수정했습니다.

## Result

[PowerPoint 내려받기](./ai-security-governance-gap.pptx)

발표 자료에는 딥페이크 피해와 탐지 한계, 주요 저작권 판례, EU AI Act 시행 흐름, 기업과 서비스 운영자가 확인할 항목을 담았습니다. 수치와 법률 정보는 2026년 7월 과제 제작 당시 조사한 자료를 기준으로 하므로 이후 활용 시 최신 출처를 다시 확인해야 합니다.

## Learned

- 여러 출처를 나열하기보다 하나의 질문과 결론으로 묶는 방법
- 역할을 나눈 병렬 검토가 내용, 디자인, 발표 전달력의 다른 문제를 찾는 데 도움이 된다는 점
- 렌더링 결과를 직접 확인해야 문서 구조만으로 찾기 어려운 오류를 발견할 수 있다는 점
