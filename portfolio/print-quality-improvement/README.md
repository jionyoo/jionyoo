# 🖨 실물사진 인화 품질 개선

> 2026.08 · Product Operations

## Background

8월 주문량이 늘면서 보정뿐 아니라 인화 · 재단 · 배송까지 생산 업무에 직접 참여했습니다.

그러던 중 재주문 고객에게서 **"화면에서 본 사진과 실제 받은 사진이 다르다"** 는 피드백이 들어왔습니다.
한 고객의 문제로 끝내지 않고, 같은 문제가 다른 주문에서도 생길 수 있는지 생산 과정 전체를 다시 점검했습니다.

## My Role

고객 피드백 분석 · 생산 과정 점검 · 문제 재현 및 원인 정리 · 개발팀과 수정 방향 협의 · 개선 결과 확인

---

## Approach

### 1. 문제를 유형별로 나누기

"사진이 이상하다"는 하나의 피드백을 실제로 확인 가능한 문제로 나눴습니다.

| 유형 | 내용 |
|---|---|
| 위치 | 사진이 한쪽으로 밀려 인화됨 |
| 색감 | 화면에서 본 색과 실제 인화물의 색이 다름 |
| 미리보기 | 앱 미리보기와 실제 출력 결과가 다름 |
| 출력 품질 | 프린터 상태에 따른 화질 저하 |

### 2. 생산 과정 단계별 점검

보정 → 파일 다운로드 → 인화 → 재단 순서로 단계마다 결과물을 확인하며 문제가 생기는 지점을 좁혀 갔습니다.

- 프린터 출력 품질과 용지 위치 설정 점검
- 같은 파일을 화면 · 출력물로 나란히 비교
- 미리보기와 실제 출력물의 차이 확인

### 3. 색 빠짐 원인 확인

색감 문제를 추적하다가, **전문 보정 프로그램에서 저장한 일부 파일(Adobe RGB 색 공간)이 생산용 파일로 변환되는 과정에서 색이 빠지는 현상**을 발견했습니다.

- 문제 주문을 기준으로 재현 경로 정리
- 피부 채도가 약 16.3% → 13.8%로 낮아지는 것을 수치로 확인
- 개발팀과 공유해 색 공간 변환 조건을 넓히도록 수정

👉 감으로 "색이 이상하다"가 아니라, **어느 단계에서 · 어떤 파일에서 · 얼마나** 달라지는지 확인해 개발 수정으로 연결했습니다.

---

## Result

- 사진 위치가 밀려 인화되는 문제 개선
- 화면과 실제 인화물의 색감 차이 조정
- 특정 색 공간 파일의 색 빠짐 원인 확인 및 수정 반영
- 같은 기간 보정 매출 전월 대비 약 52% 증가 — 늘어난 주문 속에서도 품질 유지

## What I Learned

- 디지털 화면과 실제 인화물 사이에는 차이가 생길 수 있고, 마지막 결과물까지 확인해야 품질 관리가 끝난다는 점
- 고객 피드백 하나를 **재현 가능한 문제**로 바꾸면 개발팀이 빠르게 고칠 수 있다는 점
- 운영자가 생산 과정을 직접 이해하고 있을 때 문제의 위치를 정확히 찾을 수 있다는 점
