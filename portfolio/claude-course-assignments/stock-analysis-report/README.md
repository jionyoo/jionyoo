# 📈 국내 증시 분석 리포트

**사용 도구:** Claude Cowork, Claude in Chrome, Word  
**결과물:** 국내 증시 일간 분석 리포트 5쪽

> 공개 시세와 기사로 자동 리포트 생성 과정을 연습한 과제입니다. 투자 자문이나 매매 권유 자료가 아니며, 날짜가 지난 수치는 다시 확인해야 합니다.

## Background

시장 데이터와 관련 기사를 매번 따로 확인하는 작업을 하나의 리포트 흐름으로 묶고자 했습니다. 최초 과제는 코스피 상한가 5종목 분석이었지만, 기준일에는 코스피 상한가 종목이 없어 **상승률 상위 5종목**으로 기준을 바꾸고 그 이유를 문서에 남겼습니다.

## Approach

- 다음 금융에서 종목명, 현재가, 전일비, 등락률을 확인했습니다.
- 종목별 상승 배경은 관련 기사와 기업 정보를 추가로 조사했습니다.
- 시장 요약, 종목 표, 차트, 테마 분석, 개별 코멘트, 위험 요인, 출처 순서로 읽는 흐름을 설계했습니다.
- 등락률과 절대 상승액을 별도 차트로 나눠 같은 데이터를 다른 관점에서 비교했습니다.
- 기준 변경, 권리락, 우선주 수급처럼 수치 해석에 영향을 주는 조건을 본문에 명시했습니다.

## Result

[완성 리포트 내려받기](./stock-analysis-report.docx)

시장 요약과 상위 종목 표, 차트 3개, 테마 분류, 종목별 코멘트, 출처와 면책조항을 포함한 5쪽 Word 문서를 제작했습니다.

## Learned

- 데이터가 없을 때 임의로 채우기보다 분석 기준을 바꾸고 변경 이유를 기록하는 방법
- 수치와 기사 내용을 분리해 확인하고, 결과물에 출처와 기준 시점을 남기는 방법
- 자동 생성 문서도 표 합계, 차트 값, 문장 근거를 다시 확인해야 한다는 점
